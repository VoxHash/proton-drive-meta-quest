# Contributing

1. Keep Quest packaging focused: install scripts, patches, docs.
2. Do not commit Proton Drive LFS media, secrets, or unsigned mystery APKs.
3. Any change that copies or modifies Proton Drive Android sources must remain GPL-3.0-or-later.
4. Run `./scripts/e2e-quest.sh` against a real Quest when touching launch/install paths.
5. Conventional commits: `feat`, `fix`, `docs`, `chore`, `test`.

By contributing you agree your patch is licensed under GPL-3.0-or-later.
