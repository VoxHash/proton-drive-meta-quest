# Usage

1. Launch Proton Drive from the Quest library (or `./scripts/launch-quest.sh`).
2. Sign in with Proton email/password (SRP). Complete 2FA on-device if prompted.
3. Browse My files / shares.
4. Open or download files; uploads use the app’s share/picker flows where Horizon allows.
5. If password symbols fail, focus the password field and run `PROTON_PASSWORD='…' ./scripts/quest-enter-password.sh`.
