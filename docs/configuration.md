# Configuration

| Variable | Meaning |
| --- | --- |
| `QUEST_SERIAL` | Force ADB serial |
| `JAVA_HOME` | JDK 17 path |
| `ANDROID_HOME` / `ANDROID_SDK_ROOT` | Android SDK root (must be writable for Gradle) |
| `PROTON_PKG` | Override package for launch/e2e |
| `PROTON_PASSWORD` | Used only by `quest-enter-password.sh` (never logged) |
