# Getting started

1. Enable Developer Mode on Meta Quest 3 and connect via USB (or wireless adb).
2. Confirm `adb devices -l` shows `model:Quest_3` / `product:eureka`.
3. Install JDK 17 and a writable Android SDK (`~/Android/Sdk`).
4. Run `./scripts/install-quest.sh`.
5. Sign in on the headset with your Proton account.
